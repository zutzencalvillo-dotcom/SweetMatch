SweetMatch
Sistema inteligente de recomendación de pasteles y bebidas mediante Machine Learning y AWS
1. Descripción del proyecto
SweetMatch es un proyecto que busca desarrollar una aplicación web capaz de recomendar combinaciones de pasteles y bebidas a los clientes de una pastelería.

El sistema utilizará técnicas de Machine Learning para analizar datos de compras, identificar patrones y generar recomendaciones de productos.

2. Problemática
Algunos clientes pueden tener dificultades para elegir entre diferentes opciones de pasteles y bebidas. Además, las pastelerías pueden no aprovechar sus registros de ventas para identificar las preferencias de sus clientes.

3. Solución propuesta
Desarrollar un sistema de recomendación que analice los datos de compras y sugiera combinaciones de pasteles y bebidas de acuerdo con los patrones encontrados.

4. Tecnologías
Python
Pandas
Scikit-learn
FastAPI
Amazon Web Services (AWS)
Git y GitHub
5. Dataset
El conjunto de datos inicial contiene tres columnas:

customer_id: identificador del cliente.
cake: tipo de pastel comprado.
beverage: bebida comprada.
